# Code provenance

This repository is the author-maintained public training release for UniIntervene. Release metadata is maintained independently from experiment storage and robot-deployment repositories.

Each release is identified by its source revision. Experiment artifacts should be associated with the exact checkpoint, resolved configuration, data manifest, source revision, and model/data checksums that produced them.

The public package intentionally excludes private trajectories, checkpoints, server configuration, account identifiers, and internal filesystem paths.
